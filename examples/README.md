# Example scripts

Small standalone `pypdf` demos (not required for the desktop app).

Edit the paths at the top of each file, then:

```bash
# with venv active and deps installed
python examples/merge_pdfs.py
python examples/compress_pdf.py
python examples/remove_page.py
```

For day-to-day use, prefer the desktop app (`./run.sh` / `run.bat`) or `pdfstudio.engine`.
